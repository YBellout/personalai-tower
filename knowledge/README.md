# Common knowledge

What is true across everything Yassir builds. Not architecture (that is a global
decision), not per-project (that is a charter). Every brief carries this index.

- operator.md      how he works
- conventions.md   how things are named and written
- ui.md            how his apps must behave
- glossary.md      what a word means when he says it
- domain/          facts that outlive any one project

Rules: a design file cites the knowledge it relies on; changing a file here is a
global decision and dispatches; a project may override it only visibly, in its charter.
