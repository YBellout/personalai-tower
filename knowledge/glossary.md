# Glossary

- **Hub** - ~/Documents/PersonalAI, the root everything governed lives under.
- **Governed** - every file of a project is under the root, on local disk, with a
  registry entry, a charter and a policy. The only green state.
- **Control room** - the one standing chat per project that triages bugs and
  evolutions, cuts them into orders, and is refreshed rather than run forever.
- **Promote** - the single action that moves tested code from dev/ into prod/.
- **Brief** - the generated opening context a chat reads before doing anything.
- **Handover** - the six-line record any actor writes after changing anything.
- **Closet / Store** - Closet is what he owns, Store is the supplier catalogue.
- **Adopt** - bring a garment from the Store into the Closet. Also: bring a project
  under the Tower's governance. Context decides which.
- **Spec sheet** - the per-garment document of measurements and details.
- **Original** - the brand's own product page for a garment.
