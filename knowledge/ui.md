# UI

How every governed app's interface behaves. The design system will encode this;
until it exists, this file is the rule.

- Favourite and Basket are shown as emoji only: the heart and the basket. No labels.
- Card grids for collections, filter sidebar on the left, detail view on the right.
- A detail view always shows when a value was last updated, not just the value.
- Status is a pill, not a sentence.
- Every app has a comment button, so a problem is filed by pressing it while looking
  at the problem, not by writing a paragraph afterwards.
- The apps should read as one product family, not as independent websites.

Source of the look: the Virtual Closet interface, which is the only one already
iterated on and accepted. The design system extracts from it, tokens first.
