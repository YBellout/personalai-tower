    Scope:       global

## Context

Five candidate projects, one unproven adoption pipeline, and one of them holds 4.0 GB
across 40,060 files with live work in flight. The order decides which project pays
for the pipeline's mistakes.

## Options

1. **Recommended, and taken.** The Tower itself, then AI Architecture Tower as
   docs-only, then Family School Dashboard, then Virtual Closet last.
2. Design doc sections 13 and 17 order: iExecAdmin, then Virtual Closet, then
   Academic Portal. Rejected, see D-005: iExecAdmin does not exist, and it puts the
   largest and most valuable project second.
3. Most valuable first, Virtual Closet. Proves the pipeline on the case that matters,
   and risks the one project that cannot be cheaply restarted.

## Reversibility

The order is reversible until the first project is adopted, and each adoption after
that is independent, so a later reorder costs nothing but the sequence itself. What
is not reversible is a bad adoption: step 3's frozen copy exists precisely so that
one can be undone, which is why D-003 blocks adoption and not this decision.

## Cost of not deciding

LAUNCH_PLAN.md stays a plan rather than a queue, and nothing after M0 has a subject.
