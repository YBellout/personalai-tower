# Requirements

What Yassir wants, in his words. Six fields, about two minutes to write:

    # R-017  <title>
    Project:  <id>
    Serves objective: <Ox>

    What I want, in my words:
    Done when:
    Must not break:
    How I will test it:

"Done when" becomes the automated test, written before the code.
"How I will test it" becomes the test plan handed back for acceptance.

A requirement with no "Done when" yet is simply in state `idea`. There is no
separate ideas list.
